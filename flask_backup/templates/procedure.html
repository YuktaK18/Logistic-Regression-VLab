🧭 Procedure

  1. Open Dataset Explorer, select a dataset and study its rows, columns, features, target and class balance.
  2. Open Run Experiment and select the same dataset.
  3. Select a model: a Logistic Regression variant (L2, L1, Elastic Net, none) or a comparison model (KNN, Decision Tree, SVM).
  4. Set the test size (e.g. 25%). A larger test set gives a more reliable estimate but leaves less data for training.
  5. Set C (default 1). Small C = strong regularisation (simpler model). Large C = weak regularisation (model fits training data closely).
  6. Set max iterations (default 200) and choose the solver. Keep standardisation ticked.
  7. Click Run Experiment. A real scikit-learn model is trained and evaluated.
  8. Study the metrics, confusion matrix, ROC curve, C-sweep graph and predictions table.
  9. Repeat with different settings (change one setting at a time). Every run is recorded automatically on the Observations page.
  10. Download the predictions CSV and read the auto-generated conclusion.

🔍 What each stage means

Dataset

Rows are samples, columns are features, and the target is what we want to predict.

Preprocessing

Features have different scales (e.g. 0.1 vs 1000). Standardising puts them on the same scale so the optimiser converges faster and C acts fairly on every feature.

Training

The model searches for weights that minimise the log-loss on the training set.

Testing

Predictions are made on data the model never saw — this shows how it will behave in the real world.

Evaluation

Metrics quantify how good the predictions are; plots show where the model makes mistakes.

📏 Metrics at a glance

Accuracy = (TP + TN) / (TP + TN + FP + FN)
Precision = TP / (TP + FP)Of all predicted positives, how many were right?
Recall = TP / (TP + FN)Of all actual positives, how many did we find?
F1 = 2 · Precision · Recall / (Precision + Recall)

ROC curve plots True-Positive-Rate vs False-Positive-Rate at every threshold. AUC = area under it (1.0 perfect, 0.5 random).
