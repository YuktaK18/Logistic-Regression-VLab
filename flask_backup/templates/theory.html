🎯 Aim

To implement Logistic Regression for classification, train it on a real dataset and evaluate its performance using accuracy, precision, recall, F1-score, confusion matrix and the ROC curve.

Objectives

  • Understand how a linear model + sigmoid function produces class probabilities.
  • Split data into training and testing sets and apply feature scaling.
  • Study the effect of the regularisation parameter C and the number of iterations.
  • Interpret evaluation metrics and visualisations for binary and multiclass problems.

📖 Introduction

Despite its name, Logistic Regression is a classification algorithm. It predicts the probability that a sample belongs to a class. If that probability is above a threshold (normally 0.5) the sample is assigned to that class. It is a supervised learning method — it learns from labelled examples — and is one of the most widely used baseline models in machine learning.

🧮 Mathematical Explanation

1. Linear score

z = w₁x₁ + w₂x₂ + … + wₙxₙ + b = w·x + bw = weights (learned), b = bias/intercept

2. Sigmoid (logistic) function

σ(z) = 1 / (1 + e−z)Squashes any real number into the range (0, 1)

3. Probability & decision

P(y = 1 | x) = σ(w·x + b)Predict class 1 if P ≥ 0.5, otherwise class 0

4. Log-odds (logit)

ln( p / (1 − p) ) = w·x + bThe model is linear in the log-odds

5. Loss function (Log-loss / cross-entropy)

J(w) = −(1/m) Σ [ y·ln(p) + (1 − y)·ln(1 − p) ] + (1 / 2C)·‖w‖²The last term is L2 regularisation; C is its inverse strength

6. Multiclass (softmax)

P(y = k | x) = ezk / Σⱼ ezjOne score z for each class; the probabilities sum to 1

📈 The Sigmoid Curve

When z = 0 the probability is exactly 0.5. Large positive z → probability near 1; large negative z → near 0. This is what turns a straight-line score into a probability.

⚙️ Working Principle

  1. Start with random/zero weights.
  2. Compute z and the probability p for every training sample.
  3. Measure the error with log-loss.
  4. Update the weights to reduce the loss (gradient-based optimiser such as L-BFGS).
  5. Repeat until the loss stops improving (convergence) or max iterations is reached.
  6. Use the final weights to predict probabilities for new data.

📝 Algorithm (Step-by-step)

  1. Load the dataset (features X and labels y).
  2. Split into training and testing sets (stratified).
  3. Standardise features: x' = (x − mean) / std, using training statistics only.
  4. Initialise the Logistic Regression model with C, solver and max_iter.
  5. Train (fit) the model on the training data by minimising log-loss.
  6. Predict labels and probabilities for the test set.
  7. Evaluate with accuracy, precision, recall, F1, confusion matrix and ROC-AUC.
  8. Tune C / iterations and compare results; write the conclusion.

👍 Advantages

  • Simple, fast and easy to implement
  • Gives probabilities, not just labels
  • Coefficients are interpretable
  • Works well on linearly separable data
  • Regularisation reduces overfitting

👎 Limitations

  • Assumes a linear decision boundary
  • Sensitive to outliers and unscaled features
  • Struggles with complex non-linear patterns
  • Needs reasonably independent features

🌍 Applications

  • Disease diagnosis (e.g. tumour benign / malignant)
  • Spam e-mail detection
  • Credit-risk and fraud detection
  • Customer churn prediction
  • Click-through-rate prediction
